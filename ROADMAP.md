# Roadmap

Este roadmap organiza a evolução do projeto sem prometer datas específicas.

## Próximos passos

- Adicionar testes rápidos para as implementações matemáticas puras.
- Separar dependências essenciais das dependências opcionais por módulo.
- Documentar datasets, respectivas origens e licenças.
- Tornar os exemplos reproduzíveis com seeds e métricas comparáveis.
- Adicionar notebooks introdutórios e alternativas adequadas para CPU.
- Publicar a primeira release versionada do conteúdo educacional.

## Ideias futuras

- GANs e modelos generativos.
- Reinforcement learning.
- Comparação entre arquiteturas recorrentes e Transformers.
- Exemplos de serving, monitoramento e avaliação de modelos.

Sugestões devem ser discutidas em uma issue antes de uma implementação extensa.
