# Política de Segurança

## Versões suportadas

Enquanto o projeto estiver em estágio inicial, somente a versão disponível na
branch `main` recebe correções.

## Relatando uma vulnerabilidade

Não abra uma issue pública para vulnerabilidades que possam expor usuários,
credenciais ou ambientes. Use a opção **Report a vulnerability** na aba
Security do GitHub quando disponível, ou entre em contato privadamente pelo
perfil do mantenedor.

Inclua uma descrição do impacto, passos para reprodução e uma sugestão de
correção, se possível. Não inclua dados pessoais, tokens ou credenciais reais.
